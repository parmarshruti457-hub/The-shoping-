THE SHOPING — Frontend Prototype

Open index.html in a browser.

Included:
- Premium black/gold Diwali homepage
- All-products marketplace categories
- Product grid with search and sorting
- Cart with quantity controls
- Checkout form
- Online-payment-only messaging (COD disabled)
- Order-success flow and local order history

Important:
This prototype does NOT process real payments. Before launch, connect a server-side payment gateway (e.g. Razorpay/Stripe/etc.) and verify payment server-side before creating the order and clearing the cart.
